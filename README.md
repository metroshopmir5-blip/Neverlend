# NEVERLEND — iOS starter

Оригинальный тёмный интерфейс companion-приложения для iPhone, написанный на SwiftUI.

## Что включено
- Экран демонстрационной активации ключа.
- Главный экран и вкладки «Обзор», «Камера», «Устройство».
- Локальные UI-настройки профиля FPS и чувствительности.
- Чёрно-красный премиальный стиль.

## Важно
Это UI-прототип. Ввод любого непустого ключа открывает демо-интерфейс; настоящей проверки ключей и привязки устройства пока нет. Для этого нужен защищённый сервер и отдельная реализация авторизации.

Приложение не внедряется в Oxide, не меняет игровые данные и не содержит WH, Aimbot, обхода античита или обхода блокировок. Выбор FPS здесь является только локальным профилем/заметкой и не разблокирует частоту кадров внутри игры.

## Сборка IPA
1. На Mac открой Xcode и создай новый проект iOS App с именем `Neverlend`, интерфейсом SwiftUI.
2. Замени созданный `NeverlendApp.swift` содержимым одноимённого файла из этой папки.
3. Выбери свой Team в Signing & Capabilities и укажи уникальный Bundle Identifier.
4. Выбери устройство/Any iOS Device, затем Product → Archive.
5. В Organizer выбери Distribute App и выполни подпись/экспорт IPA для своего устройства.

Требуется Xcode и Apple signing. Готовый IPA нельзя корректно подписать без учётной записи/сертификата разработчика.
